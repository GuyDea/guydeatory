# Guydeatory

**How things work — explained from the very beginning.** https://theguydea.com

Every question gets its own article, simple enough for kids of 8–10 reading alone and deep enough
for grown-ups. Highlighted terms lead to their own explanations, with a reading trail to find the
way back. Articles come with interactive diagrams, in English and Slovak.

```bash
npm install
npm run dev            # http://localhost:4321
npm run lint:content   # validate content
npm test               # unit tests
npm run check          # everything: types, tests, lint, build, built-site checks
npm run preview        # serve the build (search works here)
```
